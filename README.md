# People by Year

A simple GitHub Pages website showing years from 2014 to 2026. Click a year to see the names for that year.

## Edit the names

Open `script.js` and replace the sample names inside `peopleByYear`.

Example:

"2020": [
  "Ravi Kumar",
  "Suresh Reddy",
  "Anil Kumar"
]

You can add or remove names as needed.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open the repository's Settings → Pages.
4. Select the branch containing these files and the root folder.
5. Save.

GitHub will provide the live website URL.
